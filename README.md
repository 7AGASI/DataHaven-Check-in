1 | Запуск софта
Зайдите в папку с софтом, в строке пути введите cmd, после чего откроется командная строка

2 | Установить зависимости
pip install -r requirements.txt

3 | Настройка
📁 Подготовка (папка data)
Здесь находятся все данные юзера необходимые для работы.

keys.txt - тут вы должны поместить ваш приватный ключ из кошелька!
proxy.txt - тут вы должны подключить ваши прокси!

Каждая строка = 1 аккаунт. 

Прокси в формат http://USER:PASS@IP:PORT
Поддерживаются ТОЛЬКО HTTP прокси.

4 | Запуск (после настройки)
py main.py

В случаи ошибок при запуске обращаться в TG @AGASI_K

1 | Software launch
Go to the software folder, type cmd in the path bar, and then the command prompt opens.

2 | Install
pip install -r dependencies requirements.txt

3 | Configuration
📁 Preparation (data folder)
Here you can find all the user data you need to work with.

keys.txt - here you have to put your private key from your wallet!
proxy.txt - here you have to connect your proxies!

Each row = 1 account. 

Proxy to the format http://USER:PASS@IP:PORT
ONLY HTTP proxies are supported.

4 | Starting (after setting up)
py main.py

In case of startup errors, contact TG @AGASI_K
